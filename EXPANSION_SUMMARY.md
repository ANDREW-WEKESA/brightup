## 🆕 What Was Added (5 New Units, 225 Terms)

### 1. SOEN 101 - Introduction to Programming (40 terms)
**Topics Covered:**
- Variables, constants, data types (integer, float, string, boolean)
- Operators (arithmetic, comparison, logical, assignment)
- Control structures (if/else, switch, loops)
- Functions (parameters, arguments, return, void)
- Scope (global vs local variables)
- Arrays and iteration
- Algorithms and pseudocode
- Error types (syntax, runtime, logic)
- Debugging and comments

**Sample Terms:**
- "What named storage location holds data that can change during program execution?" → **VARIABLE**
- "What loop repeats code block specific number of times using counter?" → **FOR LOOP**
- "What process of finding and fixing errors in program code?" → **DEBUGGING**

**Target Audience:** Year 1 students, programming beginners

---

### 2. SOEN 102 - Object-Oriented Programming Basics (35 terms)
**Topics Covered:**
- Classes and objects fundamentals
- Constructors and destructors
- Attributes and methods
- Access modifiers (public, private, protected)
- Getters and setters
- Inheritance (parent/child, super/sub classes)
- Polymorphism and method overloading/overriding
- Abstract methods and interfaces
- Composition, association, aggregation
- Static vs instance methods

**Sample Terms:**
- "What blueprint defines properties and behaviors for objects?" → **CLASS**
- "What mechanism allows class to acquire properties and methods from parent class?" → **INHERITANCE**
- "What ability for objects of different classes to respond to same method call differently?" → **POLYMORPHISM**

**Target Audience:** Year 1-2 students learning OOP

---

### 3. Database Systems (50 terms)
**Topics Covered:**
- Database fundamentals and DBMS
- Relational databases and tables
- Keys (primary, foreign, composite)
- SQL commands (SELECT, INSERT, UPDATE, DELETE)
- SQL clauses (WHERE, ORDER BY, GROUP BY)
- JOIN operations (INNER, LEFT, RIGHT, FULL)
- Indexing and query optimization
- Normalization (1NF, 2NF, 3NF)
- Transactions and ACID properties
- Concurrency control, locking, deadlocks
- Views, stored procedures, triggers
- Schema and data integrity
- Backup and recovery

**Sample Terms:**
- "What column uniquely identifies each row in table?" → **PRIMARY KEY**
- "What property ensures transaction either completes fully or not at all?" → **ATOMICITY**
- "What SQL operation combines rows from multiple tables based on related column?" → **JOIN**

**Target Audience:** Year 2-3 students studying databases

---

### 4. Computer Networks (55 terms)
**Topics Covered:**
- Network types (LAN, WAN, MAN)
- Network architectures (peer-to-peer, client-server)
- OSI 7-layer model (Physical, Data Link, Network, Transport, Session, Presentation, Application)
- TCP/IP protocol suite
- IP addressing (IPv4, IPv6, subnet masks)
- MAC addresses and hardware addressing
- Network services (DNS, DHCP)
- Protocols (TCP, UDP, HTTP, HTTPS, FTP, SMTP, POP3, IMAP)
- Network devices (router, switch, hub, bridge, gateway, firewall)
- Network performance (bandwidth, latency, throughput)
- Network security (encryption, VPN)
- Packets, frames, sockets
- Network topology

**Sample Terms:**
- "What seven-layer reference model for network communication?" → **OSI MODEL**
- "What Transmission Control Protocol provides reliable connection-oriented communication?" → **TCP**
- "What device forwards data packets between computer networks?" → **ROUTER**

**Target Audience:** Year 2-3 students studying networking

---

### 5. Operating Systems (45 terms)
**Topics Covered:**
- OS fundamentals (kernel, shell)
- Process management (processes, threads, multitasking)
- Context switching and process states
- CPU scheduling algorithms (FCFS, SJF, Round Robin, Priority)
- Synchronization (deadlock, starvation, race conditions)
- Critical sections, mutex, semaphores
- Memory management (virtual memory, paging, segmentation)
- Page faults, swapping, thrashing
- File systems (directories, inodes, paths, permissions)
- System calls and interrupts
- User mode vs kernel mode
- Disk scheduling
- Device drivers

**Sample Terms:**
- "What software manages computer hardware and provides services for programs?" → **OPERATING SYSTEM**
- "What situation where processes wait indefinitely for resources held by each other?" → **DEADLOCK**
- "What technique using disk space as extension of RAM?" → **VIRTUAL MEMORY**

**Target Audience:** Year 2-3 students studying operating systems
