# 🎮 Level-Based Word Discovery Mode

**NEW!** BrightUp now includes a **Words of Wonders-style level mode** for a completely different way to learn!

---

## 🌟 Two Modes in One App

### Classic Mode (Original)
- Question & Answer format
- Multiple choice or typed answers
- Word scramble on mistakes
- Session-based learning

### Level Mode (NEW!)
- Words of Wonders gameplay
- Discover words from letter circles
- Progress through levels
- Complete crossword grids
- Earn stars and unlock worlds

---

## 🎯 How Level Mode Works

### 1. Choose Your World
- **5 Worlds** = 5 Year 3 SE units
- Each world has multiple levels
- Track progress per world

### 2. Complete Levels
Each level contains **4 terms** to discover:
- See letter circle at bottom
- Tap/click letters to form words
- Fill the crossword grid
- Find all words to complete level

### 3. Earn Stars
- ⭐ Complete level = 1 star
- ⭐⭐ Find bonus words = 2 stars
- ⭐⭐⭐ Perfect completion = 3 stars

### 4. Learn Definitions
- When you find a word, see its definition
- Terms are learned through discovery
- No pressure, no wrong answers!

## 🎮 Gameplay Features

### Letter Circle
- All letters from level's terms
- Shuffle anytime
- Tap to select
- Tap again to deselect

### Crossword Grid
- Shows how many words to find
- Horizontal and vertical hints
- Words reveal when found
- See definitions on completion

### Bonus Words
- Find extra words not in the grid
- Get bonus points (+10 per word)
- Helps earn 3 stars

### Hints System
- Show first letter hints
- Reveal word length
- Optional - use when stuck

## 🎯 Learning Benefits

### Different from Classic Mode
- **Classic:** Tests recall directly (Q&A)
- **Level:** Builds recognition first (word discovery)

### Why It Works
1. **Pattern Recognition:** See letters, form words
2. **Active Discovery:** Find terms yourself
3. **Context Clues:** Crossword structure helps
4. **Low Pressure:** No wrong answers, just discovery
5. **Progression:** Clear path through content

### Best For
- Visual learners
- Word game enthusiasts
- Less stressful revision
- Building familiarity first
- Fun alternative to Q&A
