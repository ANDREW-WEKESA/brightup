# BrightUp - Frequently Asked Questions

## General Questions

### What is BrightUp?
BrightUp is an interactive learning game designed to help computer science students master technical terminology and concepts through engaging gameplay. It features two game modes: Q&A and Level (inspired by Words of Wonders).

### Is BrightUp free to use?
BrightUp offers a freemium model:
- **Free tier**: Access to core content (875+ terms across 22 units)
- **Premium tier**: Additional features, ad-free experience, and exclusive content

### What topics does BrightUp cover?
BrightUp covers comprehensive computer science topics:
- **Year 1**: Python, Data Structures, Algorithms, OOP
- **Year 2**: Web Development, Databases, Networks, Operating Systems
- **Year 3**: Software Engineering, Security, Distributed Systems
- **Year 4**: Requirements Engineering, Cloud Computing, Machine Learning
- **Specialized**: Advanced Web Dev, HCI, Cybersecurity

## Account & Authentication

### How do I create an account?
You can sign up using:
1. **Email and password** - Create an account directly
2. **Google OAuth** - Sign in with your Google account

### I forgot my password. How do I reset it?
Click "Forgot Password" on the login page and follow the email instructions. (Feature coming soon in v1.1)

Yes, go to Settings → Account → Update Email. You'll need to verify the new email address.

### Is my data secure?
Yes! We use industry-standard security practices:
- Passwords are hashed using bcrypt
- JWT tokens for secure authentication
- HTTPS encryption for all data transmission
- Regular security audits

## Gameplay

### How do I play Q&A mode?
1. Select a unit (e.g., Python Fundamentals)
2. Choose "Q&A Mode"
3. Read the clue (question)
4. Select the correct answer from 4 options
5. Get instant feedback and move to the next question

### How does Level mode work?
Level mode is inspired by Words of Wonders:
1. You're shown a clue/definition
2. Type the correct term to answer
3. Progress through all terms in the unit
4. Track your progress with the visual indicator

### What happens if I get an answer wrong?
- You'll see the correct answer immediately
- The question may appear again later for reinforcement
- Your accuracy statistics are updated

### Can I skip questions?
Not in the free version. Premium users can use hints and skip features.

### How is my progress saved?
Your progress is automatically saved to the cloud after each session. You can pick up where you left off on any device.

## Progress & Statistics

### How is accuracy calculated?
```
Accuracy = (Correct Answers / Total Questions Answered) × 100
```

### What is a streak?
A streak counts consecutive days you've played at least one question. Streaks encourage daily practice!

### Can I view my progress history?
Yes! Go to Profile → Statistics to see:
- Total questions answered
- Accuracy per unit
- Time spent learning
- Achievement badges
- Progress graphs

### Can I reset my progress?
Yes, but this is permanent. Go to Settings → Account → Reset Progress. This action cannot be undone.

## Technical Issues

### The app won't load. What should I do?
Try these steps:
1. Refresh the page (Ctrl+R or Cmd+R)
2. Clear browser cache and cookies
3. Try a different browser (Chrome, Firefox, Safari)
4. Check your internet connection
5. Contact support if issue persists

### I'm getting authentication errors.
- Make sure cookies are enabled
- Try logging out and back in
- Clear site data for brightup.com
- Check if Google OAuth popup was blocked

### Questions aren't loading.
- Check your internet connection
- Reload the page
- Try a different unit
- Report the issue if problem continues

### The app is slow.
- Close unnecessary browser tabs
- Check your internet speed
- Try using the app during off-peak hours
- Consider upgrading your browser
